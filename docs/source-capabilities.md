# Source capabilities

Verified on **2026-11-23** unless a row says otherwise. This document separates implementation and test status from upstream availability; an endpoint responding in a probe does not mean the complete ingestion-to-dashboard path has been verified.

## Status key

- **Live shape-tested**: the public endpoint returned real data and the current parser accepted its shape during development. Persistence, scheduling, clustering, and ranking were not necessarily exercised end to end.
- **Fixture-tested**: deterministic, test-only samples exercise the parser. Fixtures never enter rankings, digests, exports, or production storage.
- **Core-tested**: application logic is tested without calling the upstream service.
- **Not implemented**: documented for the Phase 1 plan, but no working connector exists yet.
- **Credential required**: the connector can only be live-tested after Ahmad provides his own credential.

## Paid and approval-gated sources

No Phase 2 connector is implemented or enabled. X, Reddit, Instagram, the Google Trends API alpha, Calendarific, email, WhatsApp, and provider-hosted AI must remain non-blocking and off until Ahmad records a decision in [`docs/paid-decisions.md`](paid-decisions.md). TikTok has no creator-accessible official trends API in this design; use spillover evidence, deep links, and manual URLs instead of scraping.

## Truthfulness rules

- Missing measurements are `null`, not invented zeroes.
- `DEMO_FIXTURES=true` is opt-in. Test/demo rows must be visibly labeled and must never enter live rankings, digests, alerts, or exports.
- Trend market, publisher country, story location, and target audience are independent fields.
- Native metrics remain visible as provider evidence. They enter the score only where the documented scoring formula and provider terms explicitly permit it.
- A source is “live” only after its real endpoint, persistence, scheduled refresh, failure state, and UI attribution have all been verified. Fixture-only tests never satisfy that standard.
